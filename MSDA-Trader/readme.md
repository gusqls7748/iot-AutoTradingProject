# 🏆 MSDA-Trader: 4단계 철벽 방어 자동매매 파이프라인

장중 급격한 시장 변동성과 정치적 불확실성 속에서 인간의 감정을 배제하고, 오직 데이터와 알고리즘만을 기반으로 자산을 보호하며 기계적 타점을 포착하는 **퀀트 기반 자동매매 필터링 시스템**입니다.

## 🧱 1. 시스템 아키텍처 및 4단계 필터링 로직

본 시스템은 거시경제 분석부터 개별 기업의 펀더멘탈 검증까지 유기적으로 데이터가 흐르는 동적 파이프라인 구조를 가집니다. 특정 단계에서 리스크가 감지되면 하위 프로세스로의 진입을 즉시 차단하는 **위험 관리(Risk Management) 알고리즘**을 구현했습니다.

| 레이어 | 담당 모듈 | 핵심 필터링 로직 및 컷오프(Cut-off) 기준 |
| :--- | :--- | :--- |
| **LAYER 1<br>(거시경제)** | `macro_selector.py` | - 글로벌 주도 테마(미국 빅테크, 반도체 등) 실시간 동향 분석<br>- 국장 공포지수 및 KOSPI 당일 등락률 분석을 통한 시장 날씨 판정<br>- **[비상 브레이크]** 공포지수 과열 및 코스피 등락률 $-1.5\%$ 이하 폭락 시 전 종목 매수 동결 (`STORM` 락 기능) |
| **LAYER 2<br>(장중수급)** | `msda.py` | - 장중 외인 및 기관의 실시간 순매수 상위 주도주 무한 파싱<br>- 정규식(Regex) 데이터 추출을 통해 야후 파이낸스 서식 티커 리스트 동적 생성 |
| **LAYER 3<br>(차트타점)** | `technical_calculator.py` | - 최근 5일치 15분봉 데이터 실시간 다운로드 및 분석<br>- 단기 이동평균선(5일/20일/60일) 배열 상태 계산 및 RSI 지수를 통한 과매도 구간 계측<br>- RSI $< 40$ 이하의 공포 구간에서 이평선 지지 확인 시 최적의 눌림목 타점(`BUY`) 도출 |
| **LAYER 4<br>(기업체력)** | `financial_verifier.py` | - `yfinance` 기업 재무제표 요약 정보 데이터(`info`) 런타임 추출<br>- **[3대 체력 심사 기준]** 순이익률 적자 여부($< 0$), 부채비율($> 250\%$), 자본 효율성($ROE$) 심사 후 우량주에만 `PASS` 부여 |

## 📊 2. 시스템 통합 연동 및 실시간 검증 결과

### 🌤️ LAYER 1: 매크로 날씨 점검 결과
장중 한때 코스피 지수가 급락했을 당시에는 시스템이 개별 종목 분석으로 진입하지 않고 `STORM` 비상 브레이크를 작동시켜 자금을 완벽하게 보호했습니다. 이후 장마감 시점 반등 성공 및 글로벌 엔비디아 폭등세가 반영되어 `SUNNY`로 유연하게 전환되는 방어적 프로그래밍의 신뢰성을 검증했습니다.

```text

 - [국장 지수방향] KOSPI 당일 등락  : +0.15%
 - [미장 반도체] 엔비디아 단기 동향  : +6.26%
-------------------------------------------------------
결과: SUNNY ➔ ☀️ 맑음: 글로벌 매크로 및 국장 수급 안정세. 매매 진행 가능.
```
